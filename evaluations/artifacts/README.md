# Archived Raw Evaluation Reports

These 23 JSON files are unchanged copies of the locally generated evaluation reports available at archive time. They contain original assignment seed data, Codex-authored synthetic cases, model outputs and available provenance. Source bodies/attachments were checked against the committed inputs; the actual private API key and key-like values were checked without printing them. No user-uploaded source text is included. Future runner outputs remain ignored in evaluations/reports/.

These are raw observed results, not curated successful-only examples. Failures, historical settings, prompt experiments and the explicitly cancelled/excluded Mistral partial report are retained. Only Groq/Llama/Qwen expanded reports participate in the latest comparison. The whitespace-alignment smoke contains sanitized metadata for a user-email retry, not that email or its raw output.

See [evaluation protocol](../README.md), [latest comparison](../EXPANDED_COMPARISON_2026-10-06.md) and [test inventory](../../docs/TESTING.md).
